# Ипотечный калькулятор

Веб-приложение для расчёта ипотеки: аннуитетный платёж, переплата, график погашения и таблица платежей. Поддержка досрочных платежей и экспорт в Excel.

## Возможности

- **Ввод:** стоимость недвижимости, первоначальный взнос, срок (лет), процентная ставка (в т.ч. 0% — рассрочка)
- **Досрочные платежи:** добавление одного или нескольких досрочных платежей (месяц + сумма) с выбором типа:
  - **Уменьшать платёж** — пересчёт ежемесячного платежа на оставшийся срок
  - **Уменьшать срок** — платёж не меняется, сокращается срок кредита
- **Расчёт:** ежемесячный платёж, переплата по процентам, итоговая сумма кредита, примерный доход для обслуживания (40% на платёж)
- **График расчётов:** интерактивный stacked area (Chart.js) — проценты и основной долг по месяцам, подсказки при наведении
- **Таблица:** помесячные платежи, основной долг, проценты, остаток долга
- **Экспорт в Excel:** кнопка «Скачать таблицу в Excel» — сохранение графика платежей в файл `.xlsx`
- Оформление: стеклянные блоки (glassmorphism), градиентный фон, анимированные фигуры

## Технологии

- **Backend:** Python, Flask, openpyxl (экспорт Excel)
- **Frontend:** HTML, CSS, JavaScript, Chart.js 4

## Запуск

```bash
# Создать виртуальное окружение (опционально)
python -m venv venv
venv\Scripts\activate   # Windows

# Установить зависимости
pip install -r requirements.txt

# Запустить сервер
python app.py
```

Открой в браузере: **http://127.0.0.1:5000**
