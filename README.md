# Ипотечный калькулятор

Веб-приложение для расчёта ипотеки: аннуитетный платёж, переплата, график погашения и таблица платежей.

## Возможности

- **Ввод:** стоимость недвижимости, первоначальный взнос, срок (лет), процентная ставка
- **Расчёт:** ежемесячный платёж, переплата по процентам, итоговая сумма кредита, примерный доход для обслуживания (40% на платёж)
- **График расчётов:** интерактивный stacked area (Chart.js) — проценты и основной долг по месяцам, подсказки при наведении
- **Таблица:** помесячные платежи, основной долг, проценты, остаток долга
- Оформление: стеклянные блоки (glassmorphism), градиентный фон, анимированные фигуры

## Технологии

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript, Chart.js 4

## Запуск

```bash
# Создать виртуальное окружение (опционально)
python -m venv venv
venv\Scripts\activate   # Windows

# Установить зависимости
pip install -r requirements.txt

# Запустить сервер
python app.py
```

Открой в браузере: **http://127.0.0.1:5000**
